תכל׳ס – מדיניות פרטיות

עודכן: 28 באוקטובר 2026 · לדף הבית של תכל׳ס

תכל׳ס (beit-habira.com/tasks) היא אפליקציית משימות בקול שמפעיל רני איציק. העמוד מסביר איזה מידע נשמר, למה, ואיך מוחקים אותו.

מה נשמר

  • שם וכתובת אימייל מחשבון Google שאיתו נכנסת – כדי לזהות אותך ולהציג את שמך ברשימות משותפות.
  • המשימות שיצרת (שם, תאריך, שעה, דחיפות, סטטוס) והרשימות המשותפות שאתה חבר בהן.
  • מזהה מכשיר לשליחת התראות, אם אישרת התראות.
  • נתוני שימוש מצרפיים (מספר כניסות, תאריך כניסה אחרונה, סוג מכשיר) – לשיפור האפליקציה.

גישה לחשבון Google

  • Google Tasks – רק אם בחרת לחבר: יצירה, עדכון וסימון כבוצע של המשימות שיצרת באפליקציה.
  • Google Calendar – רק אם הפעלת "גם כאירוע ביומן": יצירת אירוע עם תזכורת לכל משימה עם תאריך, ועדכון או מחיקה של האירועים שהאפליקציה עצמה יצרה בלבד. האפליקציה לא קוראת ולא משנה אירועים אחרים ביומן.
  • אין גישה למייל, לקבצים, לאנשי קשר או לכל מידע אחר בחשבון.
  • הרשאת הגישה (טוקן) נשמרת בשרת מאובטח ומשמשת רק לפעולות שלמעלה.

מה לא עושים

  • לא מוכרים ולא מעבירים מידע לאף גורם, ולא משתמשים בו לפרסום.
  • לא משתמשים במידע מ-Google לאימון מודלים של בינה מלאכותית.

השימוש במידע שמתקבל מ-Google APIs והעברתו לכל אפליקציה אחרת עומדים ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use.

ספקי שירות

המידע נשמר ב-Google Firebase (מסד נתונים והתראות) ובשרת ב-Render, רק לצורך הפעלת האפליקציה.

ניתוק ומחיקה

אפשר לנתק את Google בכל רגע מתוך האפליקציה (כפתור 📅) או בכתובת myaccount.google.com/permissions. לאחר ניתוק נמחקת הרשאת הגישה. למחיקת כל המידע שלך שלח בקשה ל-ranizik@gmail.com והוא יימחק תוך 30 יום.

Takhles (תכל׳ס) – Privacy Policy

Last updated: October 28, 2026

Takhles (beit-habira.com/tasks) is a voice to-do app operated by Rani Itzik.

Data we store

  • Name and email from the Google account used to sign in, to identify the user and show their name in shared lists.
  • The tasks the user creates (title, date, time, priority, status) and the shared lists they belong to.
  • A device token for push notifications, if the user allowed notifications.
  • Aggregate usage data (visit counts, last login, device type) to improve the app.

Google user data

  • Google Tasks (https://www.googleapis.com/auth/tasks) – only if the user connects Google: create, update and complete the tasks the user created in the app.
  • Google Calendar events (https://www.googleapis.com/auth/calendar.events) – only if the user turns on "also as a calendar event": create an event with a reminder for each dated task, and update or delete only the events the app itself created. The app does not read or modify any other calendar events.
  • No access to email, files, contacts or any other account data. OAuth tokens are stored on a secured server and used only for the actions above.

Sharing

We do not sell or transfer user data to third parties, do not use it for advertising, and do not use Google user data to train AI/ML models. Data is processed only by our service providers Google Firebase and Render to operate the app.

Takhles's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Users can disconnect Google at any time from the app (📅 button) or at myaccount.google.com/permissions; the stored token is then deleted. To delete all of your data, email ranizik@gmail.com and it will be deleted within 30 days.
